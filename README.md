# Qutoof Boutique POS Demo

نسخة تجريبية محلية مخصصة لمحلات الملابس والأحذية من Qutoof Solutions. التطبيق ثابت بالكامل؛ لا يحتوي تسجيل دخول أو حسابات SaaS أو قاعدة بيانات أو API. تُحفظ المنتجات والفواتير والمرتجعات في `LocalStorage` للمتصفح الحالي.

## التشغيل والبناء

```bash
npm ci
npm run dev
```

لإنشاء نسخة Static Site:

```bash
npm run build
```

ينتج البناء ملفات الموقع الثابتة في مجلد `out/`. في Cloudflare Pages استخدم أمر البناء `npm run build` ومجلد الإخراج `out`. لم ينفّذ هذا المشروع أي نشر تلقائي.

## حدود النسخة التجريبية

- 15 صنفاً كحد أقصى.
- 20 فاتورة كحد أقصى.
- لكل متغير مقاس/لون باركود مستقل.
- الكاشير يدعم القطعة والدستة والطباعة مع تنبيه النسخة التجريبية.
- البيانات الأولية تُزرع تلقائياً في المتصفح عند أول زيارة. زر «إعادة بيانات العرض» يعيد بيانات البداية.

التغييرات والبيانات المحلية في متصفح واحد لا تتزامن بين الأجهزة، ويمكن حذفها بمسح بيانات الموقع في المتصفح.
